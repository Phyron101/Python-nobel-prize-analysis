# Visualizing the History of Nobel Prize Winners

## Overview

This project explores the history of Nobel Prize winners using Python. The analysis looks at patterns and trends within the Nobel Prize dataset and uses data visualization to help communicate the findings.

## Tools & Technologies

* Python
* Pandas
* Matplotlib
* Seaborn

## Analysis

The project involves:

* Importing and exploring the Nobel Prize dataset
* Cleaning and preparing the data for analysis
* Examining trends among Nobel Prize winners
* Analysing winners across different categories and time periods
* Creating visualizations to communicate patterns in the data

## Files

* nobel_prize.ipynb — Python analysis and visualizations
* Nobel_Prize.csv — Dataset used for the analysis
* Nobel_Prize.png — Supporting project image, where applicable

## Skills Demonstrated

Python, pandas, data cleaning, exploratory data analysis, data visualization, and communicating insights from data.
